Unity VRC MCP

Version 1.3.1 · VPM package com.data-unknown.unity-vrc-mcp

MCP server for Claude Code (and other MCP clients) that inspects and drives the Unity editor, focused on debugging VRChat avatars: animators, expression parameters/menus and live Av3Emulator inputs and states, plus VRChat SDK validation, builds and uploads.

Add to VCC / ALCOM

The button opens VRChat Creator Companion or ALCOM. If nothing happens, add this repository by hand (Settings → Packages → Add Repository):
